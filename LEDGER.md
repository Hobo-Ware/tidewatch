- **Restart keeps every shell and agent running (branch `live-handoff`, off `main`, not pushed).** The update pill's Restart no longer runs kelp-ui's `open -n` and close (that cannot pass an argument, and Kelp is out of scope): Tidewatch draws its own Restart pill once the update is installed and drives the restart itself. The old window starts the new one with `--handoff <socket>` (`open -n -a <bundle> --args ...` from a bundle, forwarding `TIDEWATCH_HOME` and `TIDEWATCH_BACKGROUND` as `--env`; the executable directly otherwise), sends the layout (repo groups, tabs in order, each group's selected tab, the group in front, focus mode, per tab its worktree, title and, for an agent, profile, level, session id, first-prompt state, notes file, workflow run file with timeout and stage generation) and the master fd of every live pty (stdusk `641ceee`, `stdusk_core::handoff`). The new window adopts them instead of restoring the session, answers ACK only when every tab is live, then arms teardown. Agent tabs are not resumed: the same process runs on. The agent's launch baked the old hook listener's port and token into its hooks and MCP address, so the layout carries the port and each agent's token (`Listener::credential_of`), and the new window binds the same port (retrying while the old process leaves, 5 s) and adopts each token under the tab's new id (`Listener::adopt_tab`). Notes, reader feeds and workflow runs re-attach from their files. The old window changes nothing until the ACK: every failure (no socket, successor never connects, protocol mismatch, no ACK) leaves it open with a notice and `closing` is cleared again.
  The single-instance socket: the old window answers `closing` for the whole hand-over, and the new window claims the socket only after the ACK with `instance::claim_replacing`, which sends nothing and waits (up to 10 s) until the old one stops answering, so a folder is never handed to a window that is leaving. A launch that cannot adopt follows stdusk's `fallback`: give way when the old window still answers, open a normal restored window when nothing does. A window with a tab being made or removed, or a workflow stage starting or running its tests, refuses to restart (that work cannot move) and says so.
