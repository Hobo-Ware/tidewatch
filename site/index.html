AI agents side by side,
one worktree each.

Tidewatch is a desktop app for macOS and Linux that runs AI coding agents in one window per git repo. Every tab is its own git worktree, a separate checkout on its own branch, so several agents can work on the same repo without touching each other's files. You watch them, read what they did, comment on their diffs and decide what ships.

$brew install hobo-ware/tap/tidewatch

Features

Run several agents without the mess.

The agent is on the left and its worktree on the right: Progress shows where the agent is, Changes what it has not committed yet and History the commits. Click a commit for its files, a file for its diff in the agent's place, and Cmd+F searches the commits.

Worktree tabs, one agent each

A new tab makes a worktree and starts Claude Code, Codex, Gemini CLI or Copilot CLI in it. Profiles set the agent, model and permission level. An agent can push its own branch, never the default branch or a tag.

Reader view

An agent tab reads as a chat on top of the live terminal: your messages as formatted text, each finished turn as its final answer with an N updates chip for the notes before it, and links you can click. A question the agent asks sits above the reply box as numbered answers, and one key picks. One shortcut flips to the raw terminal.

Notes on diff lines

Leave a note on a line of the diff, then send the notes to the agent as one message.

Your repo's way of working

Tidewatch reads your rules files to learn how a repo works: rebase or merge, fixup commits or new ones, draft or ready pull requests. You confirm it once on a card, and every message Tidewatch sends an agent names only that method.

Pull requests, asked not pushed

When the work is ready, the card says how many commits wait and offers Ask Builder to open a PR. The agent pushes and opens the pull request itself, as a draft unless your repo says otherwise; Tidewatch never does. A YOLO agent or a Meeseeks needs no approval: it decides and proceeds, and only product design and architecture questions reach you.

Overview and focus mode

Overview lists every tab with its state: working, needs you, done or failed. Focus mode hides the history so the terminal gets the whole window.

Session restore

Quitting saves your tabs. The next launch brings them back and resumes the agents where the CLI can. After a crash the agents resume by themselves; after a repeated crash, or when an agent crashed on its own, the command is typed and waits for you. A tab whose agent is not running reads Stopped and offers Resume.

Folder trust, asked once

On first launch Tidewatch asks before it marks its worktree folder as trusted in the agent CLIs' own config files. It changes nothing without a yes, and Settings can undo it.

One house style

One file, ~/.config/tidewatch/house-style.md, tells every agent how to write its answers. Edit it freely: Tidewatch never overwrites it.

Settings in your own repo

Settings and profiles can sync through a private GitHub repo you own, with your own git login.

Fresh ahead and behind counts

Open repos are fetched in the background every few minutes, so the counts on History stay current.

Keep awake with Touch ID

The Amphetamine keep-awake button can ask for Touch ID instead of your password, after a one-time setup in Settings.

Progress in the agent's own stages

Every agent keeps a progress report in two to five stages it names for the task, with its own steps under each. The Progress panel draws it: what waits on you, what the agent is doing now, the steps, what is coming up and what is not verified yet.

A done check

When an agent says it is done, Tidewatch looks at what is there: committed, pushed, pull request open, nothing left unverified, and the repo's tests, which it runs itself in the worktree. A failed check says so, and Ask agent to fix sends it back with the end of the output.

Closing a tab your way

Settings, General, Tabs sets which button Enter presses when you close a tab: delete the branch or keep it. A worktree with uncommitted changes always waits for a click.

One send line

A reply you type while the agent works is held and typed when its turn ends, one message per turn. Held messages sit under the chat to edit, delete or send now. Up and Down in an empty box bring back what you sent before, a draft is kept, and Stop interrupts the turn.

Files inside your sentence

A picture pasted with Cmd+V, a file dropped on the box and an @ pick from the repo's files each land at the cursor as a chip, and the message the agent gets carries each path in that same place.

Live pull request and issue links

Links the agent shares stay in a Links card, each with its checks, review, conflicts and comments, kept current from GitHub. Filter chips sort them by type and by what needs action, and a search finds one.

Tokens per tab

A tab's tooltip and its Overview card say how many tokens the agent has used, how much came from the cache and how many tokens Tidewatch's own messages cost. Claude Code and Codex report them; the other two do not.

Meeseeks: one task, then gone

Give the new tab one task per line and each gets its own worktree. When a Meeseeks says it is done, Tidewatch checks the work, ends the agent and keeps the branch. One that struggles turns orange and waits for you.

One profile editor

Agent, effort and permission level are one kind of choice, and a line under each says what the selected value does. Every effort and every level the agent supports is there.

Also new: every message Tidewatch sends an agent shows in the Reader with the reason it was sent and a switch to turn that kind off.

Every agent, one list.

Overview shows each tab and what it is doing, with the tabs that need you on top. A badge on the button counts them, so you can look away until one does.

  • Working, needs you, done or failed
  • The agent's own note, and a Check blocked tag when the done check fails
  • Desktop notifications when an agent needs you

Read the answer, answer the question.

The Reader turns the agent's session into text you can skim: your messages, the final answer of each turn, which tools it ran, and a question when it needs permission. Flip to the raw terminal any time.

  • Allow or deny a permission question from a button (Claude Code today)
  • Reply to the agent from a box under the answer; a reply sent mid-turn is held until the turn ends
  • Pick an answer to the agent's question with a digit key
  • Each finished turn shows its final answer, with the notes before it folded under an N updates chip
  • Your answers to its questions come back as a card, and background task notes as quiet rows

Know where an agent is.

The Progress panel reads top to bottom: the question that waits on you, what the agent is doing now, a bar for each of its stages, the steps under them, what is coming up, and what is not verified yet. A step Tidewatch ticked itself says so.

  • A question from the agent, answered above the reply box
  • A step marked checked when Tidewatch ran what it names, claimed when only the agent says so
  • Dated follow-ups under Coming up, and the links the agent shared at the bottom

Pick the agent and how far it may go.

A new tab is the form itself: an agent, a Meeseeks or a plain shell. Pick a profile and its permission level, from read only up to YOLO, name the worktree and the branch it starts from, and write the first message in the same box as the Reader's, with pictures, files and @ picks. Start, and the agent begins with it.

  • Claude Code, Codex, Gemini CLI and Copilot CLI
  • A fresh worktree and branch for every tab
  • Optional remote control, so the Claude app or GitHub mobile can drive the session

See what the agent changed.

A Changes tab sits next to History. It lists the staged, changed and new files with their line counts, and a click on a file shows its diff where the terminal was.

  • Staged, Changed and New files, each with its line counts
  • View only: the agent makes the commits

Find the commit you need.

A search field sits above History. Commits that match stay bright and the others fade, Enter steps through the matches, and Cmd+F puts the cursor in the field.

  • Matches the message, the author or the id
  • Enter and Shift+Enter jump between matches, Esc clears the search

Every link the agent shares, kept live.

Pull requests, issues, artifacts and documents the agent mentions collect in one card. Each pull request or issue shows its checks, review, conflicts and comments, from GitHub as it happens, and the ones that want you come first.

  • Chips for type (PRs, Issues, Artifacts, Docs and web) and for state (Open, Needs action, Done), each with a count
  • A search box once there are four links or more
  • The Progress tab shows an orange dot when a link starts to need action

Everything from the keyboard.

The command palette lists every command, the other open tabs and each agent profile, under group labels, with the letters you typed marked in each result. A drop-down window on a hotkey keeps Tidewatch one keystroke away.

  • Cmd+Shift+P on macOS, Ctrl+Shift+P on Linux
  • A menu-bar item on macOS
  • Update checks, notify-only unless installed with Homebrew
  • Cmd+= and Cmd+- set the interface size, 80 to 150 percent

Install

Install it with Homebrew, or grab a Linux build.

macOS gets a universal app through the Homebrew cask. Linux gets a tarball and an AppImage from the GitHub Release.

01

Install

On macOS, with Homebrew. On Linux, download the AppImage or tarball from the latest release.

$ brew install hobo-ware/tap/tidewatch
02

Open a repo

Pass the git repo you want a window for.

$ tidewatch ~/code/my-repo
03

Bring an agent

Install at least one agent CLI: Claude Code, Codex, Gemini CLI or Copilot CLI. Tidewatch finds the ones on your PATH. Pull request cards and live links need gh.

$ claude --version

Builds are not yet signed with an Apple Developer ID: the Homebrew cask clears the download flag, so the app opens without a warning. To build from source instead: cargo run -p tidewatch -- <repo>. Details are in the README.
